// 01 — color.palette
Color Palette — Light Mode
Light mode uses a warm off-white base (not pure white) so the page feels like high-quality paper, not a glaring screen. Accents shift one stop darker so they remain readable on light backgrounds.
Background Scale warm off-white · not pure white
bg-base #F8F8F7 bg-stone-50 / bg-[#F8F8F7] Page background — warm paper tone
bg-surface #FFFFFF bg-white Cards, panels — sits above the base
bg-elevated #F2F2F0 bg-stone-100 Hover states, code blocks, card headers
bg-hover #EBEBEA bg-[#EBEBEA] Active list rows, command palette highlight
Border & Text Scale warm gray · never cool gray
border-dim #ECEAE8 border-stone-200 Section dividers, subtle separators
border #E0DFDD border-[#E0DFDD] Default border — all cards, inputs
text-primary #1A1A18 text-[#1A1A18] Headlines, important labels — warm black
text-dim #6B6B67 text-stone-500 Body, descriptions, subtitles
text-muted #A8A8A4 text-stone-400 Comments, placeholders, inactive items
Accent Colors — Light Mode Adjusted One stop darker than dark mode — stays readable on white
violet — primary accent #6D28D9 violet-700 Buttons, active nav, command palette, links

// 05 — animation
Animation Direction
Animation values are identical in both modes. Only one difference: the grid background is removed in light mode — a plain warm white base is cleaner.
Scroll reveal
cubic-bezier(0.16, 1, 0.3, 1)
Duration: 400ms · opacity + translateY(16px→0)
Command palette open
scale(0.96) → scale(1) + opacity
Duration: 120ms · ease-out · closes instantly
Boot typewriter cursor
blink · step-end · 530ms
In light mode: cursor color is violet-700 (#6D28D9)
Status dot pulse
opacity 1 → 0.4 → 1
Duration: 2s · infinite · green-700 in light mode
Hover transitions
transition: all 150ms ease
bg shift: transparent → bg-hover (#EBEBEA)
Grid background
REMOVED in light mode
Too noisy on white. Replace with a plain bg-base (#F8F8F7) base only.
// 06 — tailwind.config
Tailwind Configuration — Light Mode
Use CSS variables + Tailwind's dark: modifier so both modes share one config. The class="dark" on <html> switches the whole palette.
// globals.css — CSS variable approach (recommended) :root { /* Light mode — default */ --bg-base: #F8F8F7; --bg-surface: #FFFFFF; --bg-elevated: #F2F2F0; --border: #E0DFDD; --text-primary: #1A1A18; --text-dim: #6B6B67; --text-muted: #A8A8A4; --accent: #6D28D9; /* violet-700 */ --online: #15803D; /* green-700 */ --warn: #B45309; /* amber-700 */ --link: #0369A1; /* sky-700 */ } .dark { /* Dark mode — activated by class="dark" on <html> */ --bg-base: #09090B; --bg-surface: #111113; --bg-elevated: #18181B; --border: #27272A; --text-primary: #FAFAFA; --text-dim: #71717A; --text-muted: #3F3F46; --accent: #8B5CF6; /* violet-500 */ --online: #22C55E; /* green-500 */ --warn: #F59E0B; /* amber-400 */ --link: #38BDF8; /* sky-400 */ }
// tailwind.config.ts const config: Config = { darkMode: 'class', // toggle with class="dark" on <html> theme: { extend: { colors: { /* Map CSS vars → Tailwind classes */ 'base': 'var(--bg-base)', 'surface': 'var(--bg-surface)', 'rim': 'var(--border)', 'accent': 'var(--accent)', 'online': 'var(--online)', 'warn': 'var(--warn)', 'link': 'var(--link)', }, fontFamily: { 'sans': ['Inter', 'system-ui', 'sans-serif'], 'mono': ['JetBrains Mono', 'monospace'], }, }, }, } // Usage in your components: // bg-base → uses --bg-base (light: #F8F8F7 / dark: #09090B) // text-accent → uses --accent (light: violet-700 / dark: violet-500) // border-rim → uses --border (light: #E0DFDD / dark: #27272A)
